## Теоретичні питання та пояснення

### Завдання 2. Гамма-корекція: чому 128 — неправильна відповідь для суміші чорного й білого

Значення пікселів у sRGB (0–255) не є лінійними мірами фізичної інтенсивності світла (фотонів). Вони закодовані за допомогою нелінійної гамма-кривої ($\gamma \approx 2.2$), щоб узгоджуватися з нелінійним людським сприйняттям яскравості (закон Вебера-Фехнера / ступеневий закон Стівенса): наше око набагато чутливіше до відмінностей у темних тонах, ніж у світлих.

Фізичне змішування світла відбувається **лінійно**:
1. Переводимо значення кольорів у лінійну шкалу інтенсивності $[0.0, 1.0]$:
   $$L = \left(\frac{V}{255}\right)^\gamma$$
   Для чорного ($0$): $L_1 = (0/255)^{2.2} = 0.0$  
   Для білого ($255$): $L_2 = (255/255)^{2.2} = 1.0$

2. Усереднюємо фізичну яскравість (суміш $50\%$ світла):
   $$L_{\text{mid}} = \frac{0.0 + 1.0}{2} = 0.5$$

3. Переводимо назад у простір sRGB для відображення на моніторі:
   $$V = 255 \times (L_{\text{mid}})^{1/\gamma} = 255 \times (0.5)^{1/2.2} \approx 255 \times 0.72974 \approx 186$$

Якщо наївно взяти середнє арифметичне $(0 + 255) / 2 = 127.5 \approx 128$, то фізична яскравість такого пікселя буде:
$$L = (128 / 255)^{2.2} \approx (0.50196)^{2.2} \approx 0.218$$
Тобто лише **$\approx 21.8\%$** від яскравості білого замість очікуваних $50\%$! Візуально такий колір виглядає занадто темним («брудним» або проваленим у тіні). Саме тому правильне значення суміші — **186**, а не 128.
